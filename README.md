# 🎬 Netflix Clone

A pixel-perfect Netflix homepage clone built with HTML and CSS, featuring a responsive and modern user interface.

## 🚀 Features

- Netflix-inspired landing page
- Responsive design
- Hero banner section
- Email signup form
- Language selector
- Sign In button
- Modern and clean UI
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```text
netflix-clone/
│
├── index.html
├── style.css
└── img/
```
